# Student Success Prediction 
  
## Description 
Application IA permettant d'estimer le risque de non-reussite 
academique des etudiants. 
  
## Objectifs - Analyser les resultats academiques. - Preparer les donnees. - Entrainer un modele de Machine Learning. - Produire une prediction explicable. 
  
## Technologies - Python - Pandas - Scikit-learn - Git et GitHub 
## Fonctionnalités prévues

- Collecte et préparation des données.
- Analyse et traitement des données.
- Entraînement des modèles de Machine Learning.
- Évaluation des performances des modèles.
- Prédiction à partir de nouvelles données.
